FILE: lib/bot.ts (Main LINE event processor)
================================================================================
1. Added OCR processing indicator:
   - Import pushMessages from lib/line
   - Send "กำลังอ่านสลิป..." immediately before recognizeSlip()
   - Uses retry key `${eventId}:processing`

2. Stale button confusion fix:
   - Updated changeResponse() to show clear stale message
   - "⚠️ ปุ่มนี้เก่าแล้ว (เวอร์ชันเปลี่ยนไป) กรุณาเปิด รายการค้าง หรือ รายการล่าสุด ใหม่"

3. Draft list UI - Carousel:
   - Replaced text list + 4 flex cards with single carousel (max 10 bubbles)
   - Each bubble shows: short_code, amount+category, description, date, version
   - Footer buttons: ยืนยัน, แก้ไข, ยกเลิก
   - Empty state: shows quick reply with เพิ่มรายการ/ส่งสลิป

4. Owner pairing code retrieval:
   - New command: "ขอรหัสเชื่อมต่อ" / "รหัสเชื่อมต่อ"
   - Shows LINE_PAIRING_CODE with usage instructions

5. Bulk confirm/cancel for pending drafts:
   - "ยืนยันทั้งหมด" - confirms all pending
   - "ยกเลิกทั้งหมด" - cancels all pending
   - "ยืนยันหมวด <หมวด>" - confirms by category
   - "ยกเลิกหมวด <หมวด>" - cancels by category

6. Soft delete with recovery:
   - "ล้างประวัติ" now soft deletes (deleted_at, status=cancelled)
   - New "กู้คืนประวัติ" command recovers within 7 days
   - Updated clearHistoryConfirm() text to mention recovery

7. Category quick-replies in manual entry:
   - startManualExpense() now sets edit_field='category' after description
   - User gets category quick-replies automatically

8. Inline command processing support:
   - Added INLINE_COMMANDS set for commands to process in webhook
   - processInline() calls processEvent directly and pushes response
